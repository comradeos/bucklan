# BuckLAN

Останнє оновлення: 2026-11-25

BuckLAN — утиліта для завантаження змін із папки на особистому ноутбуці до локальної папки на робочому. Наразі можна перевірити налаштування й з’єднання, отримати список вмісту та завантажити один файл.

## Перевірка папки

Для запуску достатньо Python 3.9 або новішого. Файл `bucklan.py` і папка `app/` мають бути поруч. У Windows у прикладах команд можна замінити `python3` на `py -3`.

1. Якщо поруч із `bucklan.py` ще немає `.env`, створи його з `.env.example`. Якщо файл уже є, відредагуй його.
2. Укажи шлях до наявної папки в `BUCKLAN_ROOT`. На особистому ноутбуці це папка-джерело, на робочому — папка призначення.
3. Запусти `python3 bucklan.py check`.

```dotenv
# macOS або Linux
BUCKLAN_ROOT=/Users/me/Projects/work
```

```dotenv
# Windows
BUCKLAN_ROOT=C:/Users/me/Projects/work
```

Відносний шлях обчислюється від папки з файлом `.env`. Змінна середовища `BUCKLAN_ROOT` має пріоритет над значенням із файла. Команда показує абсолютний шлях до папки, доступної для читання. У разі помилки вона виводить причину й повертає код `1`.

## Перевірка з’єднання

На особистому ноутбуці запусти сервер. Він слухає на всіх IPv4-інтерфейсах. Для зупинки натисни `Ctrl+C`.

```sh
python3 bucklan.py serve
```

На робочому ноутбуці вкажи IPv4-адресу особистого. У прикладі це `192.168.1.10`.

```sh
python3 bucklan.py ping 192.168.1.10
```

За замовчуванням обидві команди використовують порт `8765`. Якщо потрібен інший порт, задай однакове значення `BUCKLAN_PORT` у `.env` на обох ноутбуках. Значення зі змінної середовища має пріоритет. Вхідне підключення приймає особистий ноутбук, а робочий лише надсилає запит. Сервер відповідає на запит перевірки з’єднання коротким повідомленням.

## Список файлів і папок

Згенеруй спільний токен для `list` і `get`.

```sh
python3 -c 'import secrets; print(secrets.token_urlsafe(32))'
```

На особистому ноутбуці вкажи в `.env` папку-джерело та згенерований токен.

```dotenv
BUCKLAN_ROOT=/Users/me/Projects/work
BUCKLAN_TOKEN=згенерований_токен
```

На робочому ноутбуці запиши той самий `BUCKLAN_TOKEN` у `.env`. Перезапусти `python3 bucklan.py serve` на особистому. На робочому виконай команду з IPv4-адресою особистого ноутбука.

```sh
python3 bucklan.py list 192.168.1.10
```

Команда виводить відносні шляхи до звичайних файлів і папок, зокрема прихованих файлів і порожніх папок. Символічні посилання та точки повторної обробки Windows пропускаються. Сервер надає список, коли налаштовано `BUCKLAN_TOKEN`. HTTP передає токен і список без шифрування.

## Завантаження одного файла

На особистому ноутбуці запусти `python3 bucklan.py serve` з налаштуваннями для `list`. На робочому задай `BUCKLAN_ROOT` для папки призначення й той самий `BUCKLAN_TOKEN`. Вибери шлях із результату `list` і передай його команді `get`.

```sh
python3 bucklan.py get 192.168.1.10 "docs/приклад.txt"
```

Шлях відносний до `BUCKLAN_ROOT` і використовує `/` на всіх платформах. Імена мають бути сумісні з Windows. BuckLAN створює потрібні підпапки й замінює наявний файл лише після отримання всіх байтів. Символічні посилання не використовуються для читання та запису. Вміст передається через HTTP без шифрування.

## Тексти програми

Підказки команд, повідомлення й помилки редагуються в `app/messages.py`.
