# BuckLAN

Останнє оновлення: 2026-11-26

BuckLAN — утиліта для односторонньої синхронізації папки з особистого ноутбука на робочий. Команди також дають змогу перевірити налаштування й з’єднання, отримати список вмісту та завантажити окремий файл.

## Швидкий старт

Для запуску достатньо Python 3.9 або новішого. Файл `bucklan.py` і папка `app/` мають бути поруч. У Windows у прикладах команд можна замінити `python3` на `py -3`.

На кожному ноутбуці створи `.env` поруч із `bucklan.py` за шаблоном `.env.example` або відкрий наявний файл. Для першого запуску підготуй дві тестові папки. У прикладі нижче це `data/source` на особистому й `data/mirror` на робочому.

Згенеруй один токен і запиши його в `.env` на обох ноутбуках.

```sh
python3 -c "import secrets; print(secrets.token_urlsafe(32))"
```

Відносний `BUCKLAN_ROOT` обчислюється від папки з `.env`. Для нестандартного порту задай однаковий `BUCKLAN_PORT` на обох ноутбуках. Порт за замовчуванням — `8765`. Змінні середовища мають пріоритет над значеннями з `.env`.

### Особистий ноутбук — сервер

Укажи папку-джерело й заміни `згенерований_токен` на результат команди генерації.

```dotenv
BUCKLAN_ROOT=data/source
BUCKLAN_TOKEN=згенерований_токен
```

Для прикладу з `get` створи файл `docs/приклад.txt` усередині папки-джерела. Потім перевір налаштування й запусти сервер.

```sh
python3 bucklan.py check
python3 bucklan.py serve
```

Сервер слухає на всіх IPv4-інтерфейсах особистого ноутбука. Для зупинки натисни `Ctrl+C`.

### Робочий ноутбук — клієнт

Укажи наявну папку призначення й той самий токен.

```dotenv
BUCKLAN_ROOT=data/mirror
BUCKLAN_TOKEN=згенерований_токен
```

Підстав IPv4-адресу особистого ноутбука замість `192.168.1.10`. `check` показує абсолютний шлях до локальної папки, `ping` перевіряє з’єднання, а `list` показує файли й папки на сервері, зокрема приховані файли та порожні папки.

```sh
python3 bucklan.py check
python3 bucklan.py ping 192.168.1.10
python3 bucklan.py list 192.168.1.10
```

Для завантаження одного файла передай `get` відносний шлях зі списку. Використовуй `/` як роздільник на всіх платформах. Команда створює потрібні підпапки й замінює наявний файл після отримання всіх байтів.

```sh
python3 bucklan.py get 192.168.1.10 "docs/приклад.txt"
```

Для повної синхронізації запусти `sync`. **Команда видаляє зайві файли й папки в папці призначення.**

```sh
python3 bucklan.py sync 192.168.1.10
```

Для автоматичної синхронізації залиш `serve` запущеним на особистому ноутбуці й додай `--watch` на робочому.

```sh
python3 bucklan.py sync 192.168.1.10 --watch
```

Перший цикл починається одразу. Через 15 секунд після завершення циклу клієнт запускає наступний. Якщо сталася помилка, клієнт показує її та повторює спробу через той самий інтервал. Кожен успішний цикл синхронізує й видалення. Для зупинки натисни `Ctrl+C` у терміналі клієнта.

Клієнт ініціює підключення, а вхідний порт потрібен лише на сервері. HTTP передає токен і дані без шифрування.

## Як працює синхронізація

BuckLAN створює відсутні папки, зокрема порожні, і завантажує нові та змінені файли. Файли порівнюються за SHA-256. Перед заміною файла BuckLAN звіряє хеш завантаженої копії з хешем від сервера.

Після завантаження BuckLAN повторно перевіряє джерело перед видаленням зайвих файлів і папок на робочому ноутбуці. Помилка читання чи передачі зупиняє команду до початку видалення. Доступна порожня папка-джерело призводить до видалення всіх звичайних файлів і порожніх папок у дзеркалі.

BuckLAN переносить зміну регістру імені, наприклад `Report.txt` → `report.txt`. Він також замінює файл папкою або папку файлом після підготовки та перевірки всіх завантажень. Якщо встановити заміну не вдалося, BuckLAN намагається повернути попередній запис. Якщо відновлення теж не вдалося, команда показує шлях до збереженої копії.

Імена мають бути сумісні з Windows. Символічні посилання, точки повторної обробки Windows та інші спеціальні записи пропускаються. Якщо папка містить такі записи, її заміну файлом заблоковано. Імена з префіксом `.bucklan-sync-` зарезервовані для тимчасових файлів і відновлення.
